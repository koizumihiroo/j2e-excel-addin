J2E Excel Add-in

J2E は JSON テキストを Excel の値、Entity、spill 配列に変換するカスタム関数アドインです。

試用方法

必要条件

  • Excel for the web、またはCustom Functions Runtime 1.4以降に対応するMicrosoft 365版Excel for Windows。
  • 個人用Microsoftアカウントまたは組織のMicrosoft 365アカウントでのExcelへのサインイン。
  • GitHub PagesとMicrosoftがホストするOffice.jsへ接続できるインターネット接続。

ネットワーク接続は初回の関数実行時だけでなく、アドインの読み込み、数式の再計算、ブックを再度開くときにも必要になる可能性があります。オフラインでの動作は保証されません。

Excel for the web / Excel for Windows（Microsoft 365デスクトップアプリ）

  1. manifest.xml をダウンロードします。
  2. Excelでブックを開き、ホーム > アドイン を選びます。
  3. メニュー右下の + その他のアドイン を選びます。
  4. Office アドイン 画面で、ストア ではなく 個人用アドイン を選びます。
  5. 右上の 個人用アドインの管理 を選びます。
  6. アドインのアップロード を選び、ダウンロードした manifest.xml を選択してアップロードします。

組織の設定によっては、独自アドインのアップロードに管理者の許可が必要です。個人用アドインにアップロード項目が表示されない場合は、組織のMicrosoft 365管理者へ許可を依頼してください。Excelのバージョン、更新チャネル、アカウントの種類、組織ポリシーによって画面構成やボタン名が異なる場合があります。登録後は =J2E.JSON(A1) などのカスタム関数を使用できます。

プライバシー

J2E の関数コードは、受け取った JSON テキストを Excel 内で処理します。JSON の内容を J2E のサーバーへ送信する処理はありません。Excel はこのサイトから関数ファイルを読み込み、Office.js は Microsoft がホストする URL から読み込みます。
